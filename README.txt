# اپلیکیشن مدیریت پرونده‌های وکالت

## نحوه اجرا:
1. نصب Node.js: از سایت https://nodejs.org دانلود و نصب کنید.
2. دانلود پروژه و اکسترکت فایل ZIP
3. در پوشه پروژه، ترمینال باز کنید و دستورات زیر را اجرا کنید:

```
npm install
npm run dev
```

4. برنامه در مرورگر و آدرس `http://localhost:3000` اجرا می‌شود.
